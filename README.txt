Advertising Sales Prediction – Jupyter Notebook

Files:
- Advertising_Sales_Prediction.ipynb : complete analysis
- Advertising.csv : standard Advertising dataset (200 rows)

How to run:
1. Extract the ZIP.
2. Open the folder in Jupyter Notebook or VS Code.
3. Open Advertising_Sales_Prediction.ipynb.
4. Run all cells from top to bottom.

Required packages:
pandas
numpy
matplotlib
scikit-learn

Main tasks covered:
- Dataset loading and column examination
- Multiple Linear Regression
- Train/test split
- Prediction on unseen data
- Prediction for TV=150, Radio=20, Newspaper=30
- MAE, RMSE and R² evaluation
- Coefficient interpretation
- Actual vs predicted visualization
- Business and technical recommendations
